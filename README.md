# CampusNet · 校园网自动认证程序（Windows）

面向山东理工大学校园宽带门户（`http://111.17.200.130/`，城市热点 **Dr.COM / 哆点 ePortal**）实现并完成实机验证的 Windows 自动认证程序。程序在开机后于后台运行，检测到网络掉线时按退避策略自动重新认证，全过程不弹出窗口、不干扰正常使用。

除本校门户外，程序对其它厂商的 ePortal 门户提供协议适配，对通用 HTML 表单门户提供通用解析，并允许通过配置指定自定义认证接口。

- 当前版本：**3.1.1**（版本号唯一来源为 `campusnet/version.py`）
- 运行平台：Windows 10 / 11（64 位）
- 运行期依赖：**无第三方依赖**，仅使用 Python 标准库与 Windows 系统接口

> **免责声明**：本项目为个人作品，仅供学习交流与个人便利使用，与学校及任何厂商无关。请遵守学校网络管理规定合理使用。程序不绕过任何认证机制、不破解加密协议、不伪造身份；因使用本项目产生的后果由使用者自行承担。

## 一、功能特性

| 特性 | 实现方式 |
| --- | --- |
| 后台自动认证 | 后台守护进程持续巡检网络状态，掉线后按退避间隔自动完成认证，无需人工干预 |
| 开机自动启动 | 注册当前用户的启动项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`），不需要管理员权限 |
| 全程无窗口 | 后台以无控制台方式运行；调用 Windows 凭据接口时强制禁止交互界面；异常就地写入日志；子进程一律以隐藏窗口方式创建 |
| 零第三方依赖 | 仅使用 Python 标准库（`urllib` / `ssl` / `ctypes` / `subprocess` / `tkinter`）与 Windows 系统接口，无需安装任何运行期组件 |
| 多协议适配 | 支持 Dr.COM / 哆点 ePortal 专有认证接口、通用 HTML 表单门户、自定义 HTTP 接口三种认证方式 |
| 凭据本机加密 | 上网密码使用 Windows DPAPI 加密后保存，密文与本机及当前 Windows 用户绑定，离开本机无法解密 |
| 精确状态判定 | 联网状态细分为 11 种（在线、门户跳转、内容劫持、DNS 失败、超时、连接被拒、证书失败、代理拦截、网络不可达、探测目标异常、无可用探测目标），不再将网络故障一律报告为认证失败 |
| 安全的门户判定 | 仅在取得正向证据时认定认证门户；对无法确认的地址不提交账号密码 |
| 日志脱敏 | 账号、密码、令牌、长密文、内网地址、MAC 在写入日志与导出诊断包前统一打码 |

## 四、首次配置

打开程序后进入「设置」页，完成以下配置项：

| 配置项 | 填写内容 |
| --- | --- |
| Wi-Fi 名称（SSID） | 校园网无线网络名称，须与 Windows 显示的名称完全一致（区分大小写与 `-5G` 等后缀） |
| 连接方式 | 校园网为开放网络时选择「开放网络」；需要密码或企业认证的网络应先由 Windows 连接并保存，再选择「使用 Windows 已保存的配置」 |
| 连接后进行网页认证 | 保持开启。关闭后仅连接无线网络而不执行门户认证，适用于已绑定 MAC 的免认证网络 |
| 认证页面地址 | 可留空（每次自动探测），可点击「探测」由程序探测后填入，也可直接填写已知门户地址 |
| 学号 / 上网账号 | 校园网上网账号 |
| 上网密码 | 上网密码，保存时经 Windows DPAPI 加密 |
| 运营商 / 服务选项 | 按实际办理的运营商填写（如 `中国移动` / `中国电信` / `中国联通`），须与门户页面上的选项名称一致；填写错误会导致服务端返回账号密码不正确的提示 |
| 自动填写后点击登录 | 浏览器认证模式下是否自动提交，建议保持勾选 |

填写完成后点击「保存并开启自动连接」。程序将保存配置、加密密码，并尝试启动后台守护进程；启动结果会在状态栏明确显示（成功，或失败的具体原因）。

**建议后续操作**

1. 在「设置 → 启动与安全」中开启「开机自动启动后台守护」。
2. 在「设置」页点击「测试连接」，使用已保存凭据执行一次完整的“联网探测 → 认证 → 复核外网”流程。该操作不会修改配置。

## 五、日常使用

配置完成后无需日常操作，程序在后台自动维持连接。

| 操作目的 | 操作方式 |
| --- | --- |
| 查看当前状态 | 打开 `CampusNet.exe`，「概览」页顶部显示后台守护的实时状态 |
| 手动认证一次 | 「认证」页 → 「直接提交认证」 |
| 门户含验证码需人工完成 | 「认证」页 → 「打开认证页面并填写」，在浏览器窗口中完成验证码并提交 |
| 重新扫描无线网络 | 「概览」页 → 「重新扫描」，对目标网络点击「设为目标」 |
| 立即连接一次 | 「概览」页 → 「立即连接」 |
| 查看日志 | 「概览」页 → 「查看日志」 |

关闭窗口不会终止后台自动认证，此为设计行为。需要彻底停止时，使用「设置 → 启动与安全」中的停止按钮，或执行 `CampusNetCLI.exe stop`。

若更换 Windows 用户或更换计算机，程序会提示「已保存的密码在本机解不开」，此时重新录入一次上网密码并保存即可（原因见[第十节](#十安全与隐私)）。

## 六、命令行接口

`CampusNetCLI.exe` 提供以下子命令，均不需要管理员权限，且不会修改杀毒软件设置。

| 子命令 | 功能 |
| --- | --- |
| `status` / `check` | 输出当前网络状态（在线、门户跳转、DNS 失败等）与判定依据 |
| `daemon` / `service` | 输出后台守护的真实健康状态（进程、心跳新鲜度、当前状态） |
| `once` / `login` | 执行一次真实认证（会提交账号密码，仅用于排障） |
| `autostart status\|on\|off` | 查询或设置开机自启动 |
| `start` / `stop` | 启动 / 停止后台守护 |
| `wifi` / `wlan` / `ssid` | 输出无线网卡状态与附近网络 |
| `conflicts` / `overlay` / `injections` | 检查是否存在第三方叠加类软件向本程序进程注入模块（界面异常退出排查） |
| `doctor` | 导出脱敏诊断包并输出文件路径 |
| `uninstall [--remove-data]` | 卸载：停止后台守护、取消开机自启动、清理旧版遗留项；默认保留配置与日志 |
| `cleanup-legacy` | 清理旧版计划任务与启动脚本 |
| `paths` | 输出安装目录、数据目录与日志目录 |
| `version` | 输出版本号 |

常用排障命令：

```bat
CampusNetCLI.exe status      :: 当前网络状态与判定原因
CampusNetCLI.exe daemon      :: 后台守护是否真正在工作
CampusNetCLI.exe doctor      :: 导出一份脱敏诊断包
```

## 七、联网状态与门户探测模型

### 7.1 联网探测

程序不依赖系统“已连接”标记判断是否可上网，而是向三个公共探测目标发起 **HTTP GET**（默认不跟随重定向，以保留门户跳转线索），并比对返回内容或状态码：

| 探测目标 | 预期结果 |
| --- | --- |
| `http://www.msftconnecttest.com/connecttest.txt` | 正文包含 `Microsoft Connect Test` |
| `http://connect.rom.miui.com/generate_204` | 状态码为 `204` |
| `http://captive.apple.com/hotspot-detect.html` | 正文包含 `Success` |

判定原则：任一目标返回预期内容即判定为在线，以避免单一探测站点故障导致误判；全部不符合预期时，取信息量最大的失败原因作为结论。请求默认忽略系统代理，以避免本机代理软件接管探测流量而产生误判。

### 7.2 状态分类

| 状态 | 含义 |
| --- | --- |
| `online` | 探测目标返回预期内容，网络可用 |
| `redirect` | 请求被重定向到其它地址，该跳转目标通常即认证门户 |
| `hijack` | 返回 200 且内容为 HTML，流量被替换（需进一步验证是否为门户） |
| `dns-error` | 域名解析失败（未认证状态下较为常见，也可能确实未联网） |
| `timeout` | 连接超时 |
| `refused` | 连接被拒绝（本机无可用出口） |
| `tls-error` | 证书或握手失败（多为门户使用自签证书） |
| `proxy-error` | 请求被代理拦截 |
| `unreachable` | 其它网络不可达 |
| `http-error` | 探测目标返回非预期状态码 |
| `no-targets` | 配置中没有可用的探测地址 |

### 7.3 门户探测的三态结论（3.1.1 起）

「探测认证地址」功能明确定义三种结论，不再将性质不同的结果合并为同一失败状态：

| 结论 | 触发条件 | 界面表现 |
| --- | --- | --- |
| `online`（已在线） | 联网探测判定为在线 | 显示「网络连接正常」，并说明当前不需要认证门户 |
| `portal-suspected`（发现门户） | 取得正向门户证据（见下表） | 显示门户地址、门户类型与判定依据，并允许写回配置 |
| `unknown`（无法确定） | 探测失败、证据不足或结果矛盾 | 说明无法确定的原因并给出可执行建议，同时保留手工填写入口；**不写回配置，不提交任何凭据** |

正向门户证据由以下各项累积评分，达到阈值方认定为门户：

| 证据 | 权重 |
| --- | --- |
| Dr.COM / 哆点门户标记（页面注释或页面标题） | 50 |
| 含密码框的登录表单 | 40 |
| 标题包含认证页特征词 | 20 |
| 可见文字包含认证 / 门户专用词 | 10 |
| 地址或页面包含校园网网关参数（`wlanuserip`、`wlanacname`、`nasip` 等） | 25 |

候选地址返回 4xx / 5xx 状态码，或页面不具备上述证据时，一律判定为 `unknown`。

配置中已保存门户地址时，程序会校验新探测到的地址是否保留网关参数：参数更少的地址不会覆盖参数更完整的既有地址，以避免后续认证丢失必要参数。

## 八、主要配置项

配置文件为 `%LOCALAPPDATA%\CampusNet\config.json`，完整结构见 [`config.example.json`](config.example.json)。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `wifi_ssid` | 空 | 目标无线网络名称；留空表示不主动连接，仅对当前网络执行认证 |
| `wifi_connect_mode` | `open` | `open` 为开放网络；`saved` 为使用 Windows 已保存的配置 |
| `auto_enabled` | `true` | 自动连接与认证总开关 |
| `portal_auth_enabled` | `true` | 是否执行门户认证 |
| `portal_url` | 空 | 认证页面地址；留空表示每次自动探测 |
| `username` | 空 | 上网账号 |
| `password_enc` | 空 | DPAPI 加密后的密码密文，由程序生成，不应手工填写 |
| `check_urls` | 三个公共探测目标 | 联网探测目标及其预期结果 |
| `request_timeout` | `8` | 单次请求超时（秒） |
| `interval_online` | `60` | 在线状态巡检间隔（秒） |
| `interval_offline` | `8` | 掉线后重试间隔（秒） |
| `use_system_proxy` | `false` | 是否使用系统代理；默认忽略，以避免代理软件影响探测与认证 |
| `insecure_tls` | `false` | 全局关闭 TLS 证书校验。会降低安全性，不建议开启 |
| `tls_insecure_hosts` | 空 | 仅对列出的主机放宽证书校验，校园网自签证书场景的推荐做法 |
| `trusted_auth_hosts` | 空 | 允许接收账号密码的额外主机；认证接口与认证页不同域名时必须显式配置 |
| `service_option` | 空 | 运营商 / 服务选项名称 |
| `browser_fallback` | `false` | HTTP 认证失败后是否启用浏览器兜底 |
| `portal_dump_enabled` | `false` | 是否保存认证页副本（保存前自动脱敏，默认关闭） |
| `log_level` | `INFO` | 日志级别 |
| `drcom` | 见示例 | Dr.COM / 哆点 ePortal 专用参数，通常由程序自动识别与推导 |
| `custom` | 见示例 | 自定义认证接口，适用于门户不是标准 HTML 表单的情况 |

## 九、数据目录与日志

程序不向安装目录写入任何内容，全部用户数据位于独立数据目录。

| 内容 | 位置 |
| --- | --- |
| 配置（含加密后的密码） | `%LOCALAPPDATA%\CampusNet\config.json` |
| 配置备份 | `%LOCALAPPDATA%\CampusNet\config.json.bak` |
| 运行状态与心跳 | `%LOCALAPPDATA%\CampusNet\state.json`、`heartbeat.json` |
| 日志 | `%LOCALAPPDATA%\CampusNet\logs\campus_login.log` |

数据目录可通过环境变量 `CAMPUSNET_DATA_DIR` 重定向；在程序目录放置 `portable.txt` 可启用便携模式（程序目录不可写时自动回退至默认数据目录）。

日志与诊断包在写入前统一脱敏：账号仅保留前三位与后四位，密码、令牌、长密文、内网地址与 MAC 全部打码。

## 十、安全与隐私

- 本程序**不需要关闭或调整任何安全软件**，也**从不自动添加**白名单或排除项。将解释器或整个程序目录加入安全软件排除列表，会使本机所有同类程序失去防护，因此程序不提供此类功能。
- 上网密码仅保存在本机，使用 Windows DPAPI 加密，密文与当前 Windows 用户及本机绑定；复制到其它计算机无法解密，程序会明确提示并要求重新录入密码。
- 账号密码只提交给已确认的认证地址。若认证表单指向其它域名，程序默认拒绝提交并说明原因；确需提交时必须在 `trusted_auth_hosts` 中显式声明该域名。
- 默认开启 TLS 证书校验。需要放宽时建议使用 `tls_insecure_hosts` 仅对校园网门户放行，而不使用 `insecure_tls` 全局关闭校验。
- 程序从不添加杀毒软件白名单或排除项，从不关闭或修改任何安全软件设置，也不修改系统代理、DNS 或其它程序的配置。
- 程序不收集遥测数据、不上传日志。诊断包需由用户主动导出并自行决定是否分享。
- 在无法确认门户身份时，程序停止凭据提交并给出提示，不向未确认的地址发送账号密码。

## 十一、故障排查

| 现象 | 原因与处理方式 |
| --- | --- |
| 提示「探测失败：未探测到认证页面」 | 3.1.0 及更早版本的措辞问题。此类结果在当前版本中会明确区分为「网络连接正常」或「无法确定认证状态」 |
| 提示「网络连接正常：当前没有认证门户」 | 正常结果。当前网络已可访问互联网，不需要认证门户；掉线后重新探测即可 |
| 提示「无法确定认证状态」 | 探测未取得可靠结论（校园网拦截 DNS、请求超时、候选页面无法打开等）。请确认已连接校园网无线网络后重试；若仍无法探测，可在「设置」中手工填写认证页面地址 |
| 提示「没有认证门户特征」或候选地址返回 4xx / 5xx | 探测到的页面并非学校门户（可能为普通网站、运营商提示页或代理错误页）。请勿将其作为认证页使用，改为手工填写正确地址 |
| 提示「认证接口位于未确认的地址」 | 学校认证接口位于其它域名，将该域名加入配置中的 `trusted_auth_hosts` |
| 提示「TLS 证书校验失败」 | 门户使用自签证书，将该门户地址加入配置中的 `tls_insecure_hosts` |
| 提示「认证页含验证码」 | 程序不绕过验证码，请在「认证」页使用「打开认证页面并填写」人工完成 |
| 提示「网络不可达 / DNS 解析失败」 | 先确认已连接校园网无线网络；若本机运行代理或加速工具，请先退出 |
| 提示「账号或密码不正确」 | 重新录入密码，并核对「运营商 / 服务选项」是否与实际办理的运营商一致 |
| 界面窗口打开后数秒内自行消失 | 已定位为第三方叠加类软件向进程注入模块与界面库冲突所致，非程序缺陷。处理：退出该类软件，或将其配置为忽略本程序；后台自动认证不受影响，可用 `CampusNetCLI.exe status` 查看状态。排查命令：`CampusNetCLI.exe conflicts` |
| 看不到附近无线网络列表 | Windows 将 WLAN 信息归入位置相关数据。请开启「设置 → 隐私和安全性 → 位置」中的位置服务及桌面应用访问权限；也可直接在「设置」中手工填写无线网络名称 |
| 已开启开机自启动但后台未运行 | 最常见原因为所保存的密码在本机无法解密（更换过 Windows 用户或计算机）。重新录入一次上网密码并保存即可。诊断命令：`CampusNetCLI.exe daemon` |
| 界面显示「运行中但无响应」 | 后台守护进程异常。执行 `CampusNetCLI.exe stop` 后重新启动 |

## 十二、支持范围与已知限制

### 12.1 支持范围

**本项目并非适用于所有高校。** 当前已验证与未验证的边界如下：

| 认证方式 | 状态 |
| --- | --- |
| Dr.COM / 哆点 ePortal | 已实机验证可用 |
| 普通 HTML 登录表单（账号 + 密码 + 登录按钮） | 逻辑完备，未在多所学校验证 |
| 需要 JS 加密参数、专用客户端或 802.1X | 不支持全自动认证（浏览器模式可人工完成部分页面） |
| 需要图形验证码 | 不支持全自动认证，程序会停止并交由人工完成（不绕过验证码） |

### 12.2 已知限制

| 限制 | 影响与变通 |
| --- | --- |
| 联网探测使用三个依赖 DNS 的公共目标，未配置 IP 直连兜底 | 校园网若在未认证状态下拦截 DNS，三个目标均返回 `dns-error`，此时无法自动探测门户。程序会明确显示「无法确定认证状态」并引导手工填写认证页面地址，不会误报为已发现门户 |
| 联网探测将「返回 200 且内容为 HTML」判定为内容劫持 | 后台守护据此会尝试一次认证；由于提交前会校验目标主机、且找不到登录表单即停止，不会泄露凭据 |
| 门户地址的自动写回 | 仅在取得正向门户证据时写回，且不会用参数更少的地址覆盖参数更完整的既有地址 |
| 发布包体积约 33 MB | 由 onedir 打包形态决定；未使用可执行文件压缩，以避免显著增加安全软件误报率 |

完整清单见 [`docs/KNOWN_ISSUES.md`](docs/KNOWN_ISSUES.md)。

```
campus-net-login/
├─ campusnet/                 程序主体

│  ├─ portal.py               认证页解析与门户证据判定
│  ├─ portal_js.py            浏览器注入脚本

│  ├─ adapters.py             认证结果的统一结构
│  ├─ daemon.py               后台守护（状态机、心跳、退避）
│  ├─ autostart.py            开机自启动与优雅停止
│  ├─ security.py             脱敏、URL 来源校验、凭据投递策略
│  ├─ config.py               配置读取、校验、迁移与原子保存
│  ├─ status.py               统一状态模型
│  ├─ paths.py                路径策略（安装目录只读 + 用户数据目录）
│  ├─ diagnostics.py          只读安全体检与脱敏诊断包
│  ├─ ui/                     图形界面（主窗口、概览、认证、设置）
│  └─ app/                    入口分派（图形界面 / 配置向导 / 后台服务 / 命令行）
├─ tests/                     单元测试套件（unittest）
├─ tools/                     构建、冒烟、端到端与排障脚本（不进入发布包）
├─ docs/                      变更记录、已知问题、构建与验收文档
├─ packaging/                 PyInstaller 打包配置与版本资源
├─ entry.py                   单一入口（按可执行文件名或 --role 分派角色）
├─ campus_login.py            图形界面兼容入口
├─ detect_portal.py           认证页探测与字段映射排障工具
├─ build_exe.bat              构建发布包
└─ config.example.json        配置示例
```

## 十四、测试与验证

程序自带测试套件与端到端验证脚本，均可在本机执行。端到端验证使用本机模拟门户，不访问外部网络、不使用真实账号。

```bat
python tools\run_tests.py              :: 单元测试 + 旧版脚本测试
python tools\run_tests.py --exe        :: 追加打包产物冒烟测试
python tools\test_local_e2e.py         :: 本机模拟门户端到端认证验证
python tools\live_test.py --dry-run    :: 只读检查当前真实网络状态
python tools\live_test.py              :: 真实网络端到端验证（会注销当前会话，中断 10~30 秒）
```

3.1.1 版本的实机测试结果：

| 测试项 | 结果 |
| --- | --- |
| 单元测试（17 个套件） | 283 项通过 |
| 旧版脚本测试（AES 向量、`netsh` 解析、界面冒烟、浏览器自动填写） | 4 项通过 |
| 打包产物冒烟测试 | 25 项通过 |
| 本机模拟门户端到端认证（源码模式与打包模式） | 36 项通过 |
| 真实校园网门户探测（只读） | 在线场景返回「网络连接正常」；已保存门户地址场景正确识别 Dr.COM 门户及其证据 |

## 十五、构建发布包

构建需要 Python 3.9 或以上（包含 `tkinter`），以及 `requirements-dev.txt` 中列出的打包依赖。

```bat
python -m pip install -r requirements-dev.txt
build_exe.bat                        :: 等价于 python tools\build_exe.py
python tools\test_exe_smoke.py       :: 打包产物冒烟测试
python tools\make_release_zip.py     :: 生成发布压缩包与 SHA256 校验清单
```

输出目录为 `dist\CampusNet\`，包含图形界面、配置向导、后台守护与命令行四个可执行文件及运行库。构建脚本同时生成 Windows 版本信息资源并执行命令行自检。

详细说明见 [`docs/BUILDING.md`](docs/BUILDING.md)。
