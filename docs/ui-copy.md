# 界面文案规范

写界面文字时按这份走。术语和句式参考了 CampusConnect（MIT）的界面用词习惯：标签是名词短语、
帮助文字只说事实和边界条件、状态用固定词表、错误消息给"现象 + 原因 + 动作"。**不写营销话、
不写自我解释、不用语气词和感叹号。**

## 一、术语表（只准这样写）

| 概念 | 统一写法 | 不要写 |
|---|---|---|
| 无线网络名 | **Wi-Fi 名称（SSID）** | wifi 名、WIFI、网络名 |
| 目标网络 | **目标网络** | 校园 WiFi、要连的网 |
| 认证页 | **认证页面**／**认证页面地址** | 认证页、认证网址、portal |
| 认证动作 | **网页认证**／**认证** | 登录上网、验证、授权 |
| 账号 | **学号 / 上网账号** | 用户名、账号名 |
| 密码 | **上网密码** | 登录密码、口令 |
| 运营商 | **运营商 / 服务选项** | 服务商、通道 |
| 探测 | **探测认证地址** | 自动找、扫描地址 |
| 校验 | **检查上网状态** | 测试一下、看看通不通 |
| 后台进程 | **后台守护** | 后台程序、守护进程 |
| 浏览器模式 | **浏览器模式** | 内嵌浏览器、页面模式 |
| 直接提交 | **直接提交**（HTTP 认证） | 接口模式、快速模式 |

产品名、协议名按原样大小写：Windows、Wi-Fi、SSID、CSS、HTTP、CDP、Dr.COM、ePortal、Srun。

## 二、句式规则

1. **控件标签＝名词短语，句末不加标点。**
   `认证页面地址`、`学号 / 上网账号`、`运营商 / 服务选项`、`保存并开启自动连接`
2. **帮助文字＝事实 + 边界条件**，最多两句，第二句用"…时…"给出边界。
   > 填写认证网页中的完整选项名称，例如中国移动、中国联通、中国电信。网页无此选项时留空。
3. **进行中的状态用「正在 + 动作…」**（结尾用省略号「…」）。
   `正在检查上网状态…`、`正在探测认证页面…`
4. **结果是「已/未 + 状态」**，不要用形容词。
   `已认证` / `未认证`、`已提交` / `未提交`、`已连接` / `未连接`
5. **错误消息三段式**：现象（带客观信息）→ 原因（若已知）→ 动作。
   > 认证失败：服务端返回「密码错误」。请在「设置」中核对学号 / 上网账号与上网密码。
6. **说明开关行为时写清机制**，不写"帮你/自动搞定"。
   > 发现目标网络后连接，并使用已保存的账号完成认证。
7. **禁止项**：感叹号、表情符号、"试试 / 帮你 / 就好了 / 哦 / 啦"、"开心使用"、"功能强大"、
   在界面里解释设计动机（那些放 README）。

## 三、状态词表（固定 6 个）

| 值 | 文案 | 颜色 |
|---|---|---|
| 在线 | **网络正常** | 绿 |
| 离线且探测到认证页 | **需要认证** | 红 |
| 离线且未探测到认证页 | **未连接** | 橙 |
| 认证中 | **正在认证…** | 蓝 |
| 已提交待结果 | **等待认证结果** | 蓝 |
| 无法自动完成 | **需要人工处理** | 橙 |

## 四、界面文案清单

### 应用栏 / 状态栏
| 位置 | 文案 |
|---|---|
| 应用名 | 校园网自动登录 |
| 副标题 | 自动连接 · 网页认证 |
| 后台状态 | 后台守护：运行中 / 后台守护：未运行 / 后台守护：状态未知 |
| 状态栏右 | 账号密码加密保存在本机 · v3.1 |

### 概览
| 位置 | 文案 |
|---|---|
| 状态卡主行 | 已连接 {SSID} / 无线网络未连接 / 未检测到无线网卡 |
| 状态徽标 | 网络正常 / 需要认证 / 未连接 |
| 指标 | 无线网络 → {SSID}；信号强度 → {n}%；上网认证 → 已认证 / 未认证 / 检测中 |
| 按钮 | 立即连接、去设置 |
| 自动连接卡 | 标题：自动连接并认证；说明：发现 {SSID} 后连接，并使用已保存的账号完成认证。 |
| 附近网络 | 标题：附近的无线网络；副行：{n} 个网络 · 更新于 {HH:MM}；按钮：重新扫描；行内：设为目标 / 已连接 |
| 快捷操作 | 检查上网状态、在系统浏览器中打开认证页面、打开 Windows Wi-Fi 设置 |

### 设置
| 位置 | 文案 |
|---|---|
| 左栏 | Wi-Fi 名称（SSID，精确匹配）→ 与 Windows Wi-Fi 列表中的名称完全一致；后缀（如 -5G）不同视为不同网络。 |
| 连接方式 | 开放网络 / 使用 Windows 已保存的配置 → 开放网络：无已保存配置时自动创建配置文件。需密码或企业认证的网络，请先在 Windows 中连接一次并保存。 |
| 链接 | 打开 Windows Wi-Fi 设置 |
| 开关 | 连接后进行网页认证 → 关闭后仅连接 Wi-Fi，不提交认证。 |
| 右栏 | 认证页面地址（链接：探测）→ 填写认证网页地址；留空时每次自动探测。 |
| 账号 | 学号 / 上网账号 |
| 运营商 | 运营商 / 服务选项 → 填写认证网页中的完整选项名称。网页无此选项时留空。 |
| 密码 | 上网密码 → 已保存密码；留空表示不修改。 |
| 勾选 | 自动填写后点击登录 |
| 高级 | 高级设置 · 特殊认证页面 → 留空时自动识别。 |
| 选择器 | 账号输入框 / 密码输入框 / 登录按钮（CSS 选择器） |
| 兜底 | 认证失败时用浏览器重试 → 后台认证失败后打开浏览器重新认证。会弹出窗口，仅在需要时开启。 |
| 按钮 | 保存并开启自动连接、保存设置 |
| 页脚 | 账号密码加密保存在本机；更换电脑后需重新填写。 |

### 错误消息模板
| 场景 | 文案 |
|---|---|
| 缺配置 | 尚未配置认证页面地址。请点击「探测认证地址」，或在「设置」中填写。 |
| 缺账号 | 尚未填写学号 / 上网账号。请在「设置」中填写。 |
| 缺密码 | 尚未保存可用的上网密码。请在「设置」中填写。 |
| 密码解不开 | 已保存的密码无法在本机解密（更换电脑或 Windows 用户后需重新填写）。 |
| 凭据被拒 | 服务端拒绝该账号或密码。请在「设置」中核对后重试。 |
| 网络不通 | 网络不可用（{原因}）：{详情}。 |
| 浏览器缺失 | 未找到 Edge 或 Chrome，无法打开认证页面。 |
| 页面地址不符 | 页面地址与已保存的认证页面地址不一致，已停止填写。 |
| 需验证码 | 认证页面要求填写验证码，请在窗口中完成。 |
